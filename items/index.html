集計方法

  • データ元：Deadlock API が公開しているランクマッチのデータ。
  • 対象の試合：その週のランクマッチを両チームの平均ランクの高い順に並べ、上位約10%に入る試合。リージョンは問いません。境目のランクは毎週の分布から決めるため、週によって少し変わります。
  • 集計期間：日本時間の土曜 0:00〜金曜 24:00。毎週土曜に自動で更新します。
  • 使用率 ＝ そのアイテムを1回以上買ったプレイヤー数 ÷ 対象の試合の全プレイヤー数（1試合12人）。後で売却した場合も「買った」に数えます。
  • グラフはカテゴリごとに使用率の上位20アイテムです。全アイテムの数値は GitHub の data/items フォルダに週ごとの CSV で保存しています（）。
  • グラフの棒にカーソルを合わせるかタップすると、購入人数と前週の使用率を確認できます。

注意事項

このサイトは非公式のファンプロジェクトです。Valve および Deadlock API とは関係がなく、承認も受けていません。Deadlock とアイテムのアイコンは Valve Corporation の著作物・商標です。

使用率は「どれだけ買われたか」であり、アイテムの強さそのものではありません。使うヒーローがピックされていない、相手の構成によって買う、といった事情でも数値は動きます。各週の数値は更新時点のデータで、後から追加された試合は反映していません。
